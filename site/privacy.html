적용 대상: Dragondydals File Transfer의 Google Drive 파일 전송 기능. 최종 수정: 2026년 9월 27일.

접근 정보와 목적

계정 확인을 위해 이메일 주소에 접근할 수 있습니다. 파일 조회·전송·백업·복원을 위해 파일명, 경로, 식별자, 크기 등 메타데이터와 처리 대상으로 지정된 파일 내용에 접근합니다. OAuth 접근 토큰과 갱신 토큰은 인증 및 접근 권한 유지에 사용합니다.

저장과 전송

인증 정보는 공개 사이트나 공개 소스 저장소에 포함하지 않습니다. 로컬 설정에서는 인증 정보를 암호화하여 보관합니다. RunPod에서 사용할 경우 해당 실행 환경이 인증 정보에 접근할 수 있도록 별도 설정이 필요합니다.

사용자가 실행하거나 설정한 자동화에 따라 파일이 Google Drive, 로컬 컴퓨터, RunPod 사이에서 전송됩니다. 각 서비스는 해당 서비스의 정책에 따라 데이터를 처리합니다. 이 파일 전송 기능은 Google 사용자 데이터를 광고나 판매 목적으로 사용하지 않습니다.

보관 및 삭제

인증 정보는 연결을 유지하는 동안 보관하며 사용자가 저장 위치에서 삭제할 수 있습니다. 전송된 파일과 백업은 사용자가 삭제하거나 별도로 설정한 보관 정책에 따라 삭제할 때까지 남을 수 있습니다. 작업 로그에는 파일명, 경로, 처리 상태 등이 포함될 수 있으며 실행 환경의 보관 설정이 적용됩니다.

연결 해제

Google 계정 연결 관리에서 접근 권한을 취소할 수 있습니다. 연결 해제만으로 기존에 복사한 파일·백업·로그가 삭제되지는 않으므로 각 저장 위치에서 별도로 삭제해야 합니다.

안내 사이트

이 페이지는 정적 안내 문서이며 자체 로그인, 파일 업로드 또는 분석 스크립트를 사용하지 않습니다. GitHub Pages로 게시할 경우 호스팅 제공자가 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요.
